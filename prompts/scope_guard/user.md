## Görev

Yalnızca şu JSON şemasına uyan bir nesne döndür, başka hiçbir açıklama ekleme:

```json
{
  "group_id": "olive_and_oil",
  "reason": "kısa gerekçe"
}
```

Makale kapsam dışıysa `group_id` alanına tam olarak `"out_of_scope"` yaz.
