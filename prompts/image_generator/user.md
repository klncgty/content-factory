## Görev

Yukarıdaki **başlığın konusunu** gösteren bir fotoğraf sahnesini İngilizce tarif et.
Bölüm başlıkları yalnızca konuyu netleştirmen için verildi; sahne başlığa dayanmalıdır.

Yalnızca şu JSON nesnesini döndür, öncesine/sonrasına hiçbir şey yazma:

```json
{
  "scene": "İngilizce sahne tarifi"
}
```

`scene` alanı İngilizce, tek cümle ve yalnızca görülebilecek nesnelerden oluşmalıdır.
Sahnede yazı, etiket, ambalaj metni veya başlığın kendisi bulunmasın.
