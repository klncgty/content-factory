## Görev

Yalnızca şu JSON şemasına uyan bir nesne döndür, başka hiçbir açıklama ekleme:

```json
{
  "meta_title": "50-60 karakter arası başlık",
  "meta_description": "150-160 karakter arası açıklama",
  "secondary_keywords": ["gövde metninde doğal geçen ikincil kelimeler"]
}
```
